## Notas de ejecución y verificación

1. Antes de cada POST, comprueba IDs, precio, stock y estado actuales: los datos de la base pueden cambiar entre intentos.
2. Muestra SPA y DevTools > Network en la captura cuando corresponda; selecciona la petición para que se lean método, estado HTTP, Payload y Response. En cálculos, incluye la multiplicación o suma manual.
3. Para una validación que impide enviar la petición, captura el formulario y Network sin solicitud nueva. Repite la regla desde Postman cuando se indique.
4. Si el resultado difiere del esperado, conserva el resultado real, marca **Falla** y crea una ficha en el informe. Nunca cambies la evidencia para que coincida con el esperado.
5. Los POST válidos alteran ventas y stock. Usa productos de prueba y anota el ID de cada venta para poder verificar después el comprobante y el inventario.
